# StepByStep

Образовательная платформа для построения портфолио и поступления в зарубежные университеты с помощью ИИ.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000. Анкета профиля — `/onboarding`.

## Что внутри

- `/` — главная, `/onboarding` — анкета школьника, `/dashboard` и соседние разделы — платформа.
- `/share` — анкета для поступивших, `/admin` — база знаний ИИ-наставника.
- Архитектура RAG и задачи для ML-инженера: [docs/RAG.md](docs/RAG.md).
- Переменные окружения: [.env.example](.env.example).
